## 🚀 How to Use This Repository

### Prerequisites

- C++ compiler (g++, clang, or MSVC)
- Code editor or IDE (VS Code, Dev C++, etc.)

### Compiling and Running Programs

**Using g++:**

```bash
g++ -o program_name filename.cpp
./program_name
```

**Using cl (Visual Studio C++):**

```bash
cl filename.cpp
filename.exe
```

### Recommended Learning Path

1. Start with **0_Basic_C++/** - Learn fundamentals
2. Progress to **1_Array/** - Master array operations
3. Move to **2_String/** - String manipulation
4. Study **3_Pointers/** - Memory management
5. Master **4_Recursion/** - Advanced problem solving

## 📖 Compilation Commands

### Compile single file:

```bash
g++ -o output filename.cpp
```

### Compile with optimization:

```bash
g++ -O2 -o output filename.cpp
```

### Compile with debugging info:

```bash
g++ -g -o output filename.cpp
```

### Run with input:

```bash
./output < input.txt
```
